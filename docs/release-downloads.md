## Choose your download

| Computer | Install x-reader | Run it portably |
| --- | --- | --- |
| Windows x64 | Run the file ending in `setup.exe`. | Extract the Windows portable ZIP, then open `x-reader.exe`. |
| macOS 15 or later, Apple Silicon or Intel | Open the universal DMG and drag x-reader to Applications. | Extract the macOS portable ZIP and open the app inside its folder. |

A portable copy keeps books, bookmarks and notes in the adjacent `data` folder. Move the whole folder with the app closed. Windows uses Microsoft Edge WebView2. The Windows binaries are unsigned. The universal Mac app is ad hoc signed and has no Apple notarization. [First-launch instructions and checksums](https://github.com/realsaraf/x-reader/blob/main/docs/RELEASING.md)

Choose **Read the sample** to open *The Quiet Atlas*, or use **Add books** to bring your own. A PDF opens in reading view. Select **Original PDF** to see the printed page. [Watch the 24-second walkthrough](https://raw.githubusercontent.com/realsaraf/x-reader/main/docs/media/demo.mp4)
